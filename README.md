# pavibamunu

Portfolio of Pavithra Bamunu: customer and business analytics, Auckland. Live at https://pavi44m.github.io/pavibamunu/

- `index.html`: home, with the "identity resolve" opening sequence
- `catchment-slab.html`, `catchment-command.html`, `method.html`: the Catchment Mission Fit study, dashboard and working
- `cv.html`: CV, filtered by capability
- `assets/hud.css`, `assets/hud.js`: the shared layer on every page (navigation bar with Auckland time, living background, pointer light). Pages that draw their own background set `<html data-hud-bg="off">`.

Static files only; no build step. Respects reduced-motion and works without JavaScript.
